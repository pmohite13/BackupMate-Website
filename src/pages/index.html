Two installers and a wizard

  1. Install the serverOn any Windows PC with spare disk space: a desktop that stays on, or an old machine in the corner. It needs nothing set up first.
  2. Install the clientOn each PC you want protected. Paste the code the server gives you, tick the folders that matter, pick a time.
  3. Leave it aloneBackups run on schedule, whether or not anyone is logged in. You get an email if one fails or a PC goes quiet.
  4. Get files backFrom the PC itself, or from the server when the PC is the thing that broke. Pick a day, pick the files, restore.

Built for the day something goes wrong

{{icon:shield-check}}

Encrypted before it leaves the PC

Each computer encrypts its own files with AES-256. The server stores data it cannot read unless you choose otherwise.

{{icon:archive-restore}}

Deleted backups come back

Nothing a PC deletes from the server is gone at once. It is kept for 30 days, so malware on one machine cannot wipe everyone's history.

{{icon:life-buoy}}

Restore never stops working

If your licence lapses, backups for extra PCs pause. Getting your files back is never restricted, licensed or not.

{{icon:mail-check}}

It tells you, plainly

An email when a backup fails, when a PC has not backed up for a while, and when it recovers. In words, not error codes.

{{icon:layers}}

Small after the first run

Only what changed is sent, and identical files across the office are stored once. Open files such as a live accounts database are captured properly.

{{icon:layout-dashboard}}

One screen for the whole office

See every PC, when it last backed up and whether it is overdue. Recover a broken machine's files without the machine.
