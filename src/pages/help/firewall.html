PCs cannot reach the server

On a PC, Connect fails or times out, or backups say The backup server could not be reached.

Most often: the server's firewall

Windows Firewall on the server blocks incoming connections until told otherwise, and the installer does not change it. On the server, in PowerShell as administrator:

New-NetFirewallRule -DisplayName "BackupMate storage" -Direction Inbound -LocalPort 8443 -Protocol TCP -Action Allow -Profile Private,Domain
New-NetFirewallRule -DisplayName "BackupMate control" -Direction Inbound -LocalPort 8444 -Protocol TCP -Action Allow -Profile Private,Domain

If your network is marked Public in Windows, change it to Private (Settings → Network → your connection), or the rules above do not apply.

Then check the address

  • Use the server's computer name or its IP address, exactly as you would to open a shared folder on it.
  • From the PC, in PowerShell: Test-NetConnection SERVER -Port 8444. TcpTestSucceeded : True means the PC can reach it.
  • If it works by IP address but not by name, use the IP address, or fix the name in your router.

Still not working

Make sure the BackupMateServer service is running on the server (Services app), and that both machines are on the same network. Then send us diagnostics from both.
