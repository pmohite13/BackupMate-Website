I forgot the passphrase

Each PC encrypts its backups with the passphrase chosen when it was connected.

If your server keeps a copy of the keys

If the server was set up to hold the keys, an administrator can recover that PC's files from the server's Recover page without the passphrase. See Restoring files.

If it does not

Then the backups cannot be opened without the passphrase, by anyone, including us. That is what makes them private. There is no reset and no back door.

  • Look wherever passwords are kept: a password manager, a note in a safe, the person who set the PC up.
  • The PC itself still backs up and restores normally, because it has the passphrase stored securely. Only connecting it, or another PC, to those backups again needs it typed.
  • If it is truly lost, make sure the PC keeps backing up, and from now on keep the passphrase in a password manager.

Not solved? Contact us, and attach diagnostics if you can.
