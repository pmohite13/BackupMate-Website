“The backup server could not be reached”

A backup failed, or the PC's window says The backup server could not be reached. Check that it is switched on and on the same network; this machine will keep trying.

Why

Usually something temporary: the server was off or restarting, the PC was away from the office, or its Wi-Fi dropped. BackupMate checks the server is reachable before blaming anything else, so this message means exactly what it says.

What to do

  • Nothing, if the cause is gone. The PC tries again by itself and catches up on the backup it missed.
  • If it keeps happening: check the server stays switched on and does not go to sleep (Settings → System → Power on the server), and see PCs cannot reach the server.
  • A laptop on unreliable Wi-Fi will see this now and then. A network cable for the first, large backup helps.

Not solved? Contact us, and attach diagnostics if you can.
