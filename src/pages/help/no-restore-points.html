Help › Restoring

“No restore points yet”

On a PC, Restore says there are no restore points yet.

Check first

  • Has it backed up? The backup's line should say backed up with a date. A new backup has no restore point until its first run finishes; press Run now and wait for it.
  • Is it the right backup? Restore points belong to the backup they were made by. Look under the backup that held the files.
  • Is it on an old version? Versions before 0.4.6 could show this wrongly while the server had the backups. Upgrade the PC.

If the server has them

If the server's Recover page lists restore points for this PC but the PC does not, send us diagnostics from the PC. You can recover the files from the server meanwhile, if it keeps the encryption keys.

Not solved? Contact us, and attach diagnostics if you can.
