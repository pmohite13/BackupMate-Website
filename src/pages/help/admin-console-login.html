Opening the server's console: browser warning and password

The browser says the connection is not private

The server's console uses a certificate the server issued itself, which your browser does not know. The connection is still encrypted. Choose Advanced, then continue to the site. To stop the warning permanently, install the server's ca.pem as a trusted root certificate on the computers you open the console from.

The password

Sign in as admin. The password was generated when the server was installed and is in:

C:\ProgramData\BackupMate\Server\ca\admin-password.txt

Only an administrator on the server can open that file.

Opening it from another PC

The console is at https://SERVER:8445. Opening it from another computer also needs port 8445 allowed through the server's firewall, as in PCs cannot reach the server.
