“Backed up, N files skipped”

A backup shows as backed up, with a note such as 3 files skipped because they could not be read.

What it means

Everything else in the folder was backed up. The files named were not. BackupMate carries on past a file it cannot read, rather than failing the whole backup over it, and tells you which ones.

Why a file cannot be read

  • Antivirus blocked it. Most common: a file the antivirus has flagged or quarantined, often a download or an old installer. Check your antivirus's history.
  • It is not yours to read. A file whose permissions shut out even the system account, such as one copied from another computer.
  • It vanished. A temporary file deleted between being listed and being read. Harmless.

What to do

Press History on that backup to see the files named. If they matter, deal with the cause above and the next backup will include them. If they are junk, add them to Skip these under Edit so they stop being reported.

Not solved? Contact us, and attach diagnostics if you can.
