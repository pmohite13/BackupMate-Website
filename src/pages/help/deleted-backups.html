Backups have gone missing or were deleted

Restore points you expect are not there, or backups were deleted by mistake, or by malware on one of the PCs.

They can usually be put back

Nothing a PC deletes from the server is gone at once. It is kept for 30 days in a recycle bin only the server controls.

  1. Stop and find the cause first if you suspect malware: disconnect the affected PC from the network.
  2. On the server: Settings → Storage and protection → Deleted backup data.
  3. Enter how many hours back to go, to a time when things were still right, and press Put deleted data back.

It puts back what was deleted since then and keeps anything written since. It never changes files on the PCs themselves. Tell us if this happened; we will help make sure it does not again.

Not solved? Contact us, and attach diagnostics if you can.
