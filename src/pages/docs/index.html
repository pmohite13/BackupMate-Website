Guides

Short, in order, and written for the person who looks after the office PCs rather than for an engineer.

Quick start

Install the server, connect the first PC and take the first backup. About fifteen minutes.

Restoring files

Get a file, a folder or everything back: on the PC, or from the server when the PC is gone.

Upgrading

Move to a newer version without losing settings or backups.

Silent install

Install on many PCs from a script or a deployment tool.
