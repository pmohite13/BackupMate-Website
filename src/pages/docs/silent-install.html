Silent install

Both installers are standard Windows Installer packages. They install without prompts, so they work with Group Policy, Intune, PDQ, an RMM tool or a plain script.

Commands

Run from an elevated prompt, or as SYSTEM from your deployment tool. Use the file names as you downloaded them; they include the version number.

Install the clientmsiexec /i BackupMate.msi /qn /l*v install.log
Install the servermsiexec /i BackupMateServer.msi /qn /l*v server-install.log
UpgradeThe same command with the newer file. It upgrades in place and keeps settings and data.
Uninstallmsiexec /x BackupMate.msi /qn
  • /qn shows nothing. Use /qb for a progress bar only.
  • /l*v writes a full log, which is what to send us if an install fails.
  • Installing silently accepts the licence agreement on behalf of your organisation.

What a silent install does and does not do

It installs the software and starts the service. It does not connect a PC to your server: that still needs the server's addresses, its certificate, a one-time enrolment token and a passphrase, entered in the BackupMate window on that PC. See the quick start, steps 5 to 9.

If you are rolling out to many PCs and want the connection scripted as well, write to us. It can be done with a prepared configuration, and we would rather set it up with you than have you guess at it.

What is installed where

ProgramsC:\Program Files\BackupMate
Settings, logs and (on the server) backupsC:\ProgramData\BackupMate
ServicesBackupMate on a PC, BackupMateServer on the server. Both start automatically.

Uninstalling removes the programs and the service. It leaves C:\ProgramData\BackupMate alone on purpose, so that reinstalling picks up where it left off and so that an uninstall can never be the thing that deletes your backups.

Firewall

The client needs no inbound ports. The server needs TCP 8443 and 8444 open to the office network, and 8445 if you want to open its console from another machine. The installer does not change the firewall; see step 3 of the quick start.

Verifying the installers

Compare each file's SHA-256 with the one on the download page before deploying it:

Get-FileHash .\BackupMate.msi -Algorithm SHA256
