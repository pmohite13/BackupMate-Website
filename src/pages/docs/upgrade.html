Upgrading

Run the new installer over the old one. Settings, connections and backups are all kept. Nothing needs uninstalling or deleting.

The order

  1. Server first. Download the new BackupMateServer installer and run it on the server. The service restarts by itself; PCs that were mid-backup carry on at their next run.
  2. Then each PC. Run the new BackupMate installer on each one. It does not need to be the same day.

A PC on an older version normally keeps backing up to a newer server in the meantime. When a release needs every PC upgraded promptly, its notes on the download page say so.

Knowing who is behind

  • The server's Fleet page shows the version each PC runs and marks any that are older than the server.
  • A PC that is behind says so in its own BackupMate window.
  • When a newer BackupMate is published, the server's console says so on the Fleet page and under Settings → Support. This needs the server to reach the internet once a day, and can be switched off there.

Do not

  • Do not uninstall first. It is unnecessary, and deleting the data folder afterwards would disconnect the PC from its backups.
  • Do not delete C:\ProgramData\BackupMate. On a PC it holds the connection to the server and the sealed passphrase. On the server it holds the certificate authority that every PC trusts, and by default the backups themselves.
  • Do not install an older version over a newer one. The installer refuses.

Before upgrading the server

It is good practice to have your second copy of the server's storage up to date first. Upgrades do not touch the stored backups, but the day you upgrade is a sensible day to check that copy exists.

If something is wrong afterwards

Export a diagnostics file from the PC or the server and send it to us. It records the version and the log, which is what we need to see.
