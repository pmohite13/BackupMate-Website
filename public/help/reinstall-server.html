Reinstalling or upgrading the server

Upgrading

Run the new installer over the old one. Everything is kept. See Upgrading.

Reinstalling

Uninstalling removes the programs and leaves C:\ProgramData\BackupMate\Server alone, deliberately. Installing again picks up where it left off: the same certificate, the same PCs, the same backups.

Never delete

  • C:\ProgramData\BackupMate\Server. It holds the certificate every PC trusts, the server's keys and its records. Deleting it disconnects every PC.
  • The storage folder, which holds the backups themselves.

Moving to new hardware

Write to us first. It is straightforward, but the order matters, and your licence needs reissuing for the new server.

Not solved? Contact us, and attach diagnostics if you can.
