Scan does not find the server

On a PC, Scan under Backup servers finds nothing.

Why

Scan uses network discovery (mDNS). Some routers and Wi-Fi access points block it, and it does not cross from one network segment to another. The server may also simply have been started a moment ago and not announced itself yet.

What to do

Press Connect… and type the addresses yourself:

  • Control URL: https://SERVER:8444
  • Storage URL: https://SERVER:8443

where SERVER is the server's computer name or IP address. Scanning is only a shortcut; everything works the same without it. If typing the address fails as well, see PCs cannot reach the server.

Not solved? Contact us, and attach diagnostics if you can.
