Email alerts are not arriving

On the server: Settings → Email alerts. After saving, always press Send test email.

The usual causes

  • Port. Use 587. Port 465 will not work: BackupMate starts a plain connection and upgrades it, which 465 does not allow.
  • Password. Gmail and Microsoft 365 accounts with two-step verification need an app password, created in the account's security settings, not the account's normal password.
  • Spam folder. Check it before changing anything else.
  • Server. Gmail is smtp.gmail.com; Microsoft 365 is smtp.office365.com.

The test reports exactly what the mail server said. Alerts are always written to the server's Event Log as well, whether email works or not.

Not solved? Contact us, and attach diagnostics if you can.
