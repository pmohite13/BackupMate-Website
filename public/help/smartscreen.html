Windows says “Windows protected your PC”

When you run a BackupMate installer, Windows may show a blue box saying Windows protected your PC.

Why

The installers are not yet signed with a code-signing certificate, so Windows does not recognise who published them. It shows this for any unsigned program, not because anything is wrong with the file. Signing is in progress.

What to do

  1. Check the file is the one we published: compare its SHA-256 with the one on the download page. In PowerShell, in the folder you saved it to: 
    Get-FileHash .\BackupMateServer-0.4.13.msi -Algorithm SHA256
    It must match letter for letter. If it does not, do not run it; download it again.
  2. Run the installer, choose More info, then Run anyway.

Not solved? Contact us, and attach diagnostics if you can.
