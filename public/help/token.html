“That enrolment token is not valid, or has already been used”

Connecting a PC fails with That enrolment token is not valid, or has already been used.

Why

A token connects one PC, once. It is used up as soon as a PC connects with it, so a token that worked for the last PC will not work for this one.

What to do

  1. On the server, open BackupMate Admin Console.
  2. Go to Settings → Licence and machines → Add a machine and press Create an enrolment token.
  3. Copy it straight away: it is shown only once. Use it on the PC.

A PC that is already connected to this server does not need a token to connect again.

Not solved? Contact us, and attach diagnostics if you can.
