“The backup server's storage no longer holds this machine's backups”

A PC says The backup server's storage no longer holds this machine's backups. The server's storage folder may have been changed, emptied or replaced.

Why

The PC reached the server, but the storage folder the server is using does not contain this PC's backups. Usually the folder in the server's settings was changed, a drive letter changed (an external disk that came back as a different letter), or the folder was emptied or restored from somewhere else.

What to do

  1. Do not delete anything, on the server or the PC.
  2. On the server, check where it says the backups are: Settings → Storage and protection → Backup storage. Is that the drive and folder they have always been in?
  3. If a drive letter changed, give the drive its old letter back (Disk Management), and restart the BackupMateServer service.
  4. If you are not sure, send us diagnostics from the server and the PC before changing anything.

Not solved? Contact us, and attach diagnostics if you can.
