Certificate error when connecting a PC

Connecting a PC fails with an error mentioning a certificate, often signed by unknown authority.

Why

Each PC checks that it is talking to your server, and not something pretending to be it, using the file ca.pem from that server. The error means the PC was given the wrong file, an old one from a previous installation of the server, or a path that does not point at it.

What to do

  1. On the server, copy C:\ProgramData\BackupMate\Server\ca\ca.pem again (never ca.key, which sits beside it).
  2. Put it on the PC, for example at C:\ProgramData\BackupMate\ca.pem.
  3. Connect again, with that exact path in CA certificate file.

If the server was reinstalled, its certificate changed, and every PC needs the new ca.pem.

Not solved? Contact us, and attach diagnostics if you can.
