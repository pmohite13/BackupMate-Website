Then follow the quick-start guide. It takes about fifteen minutes for the first PC.

Windows will warn you about these installers. They are not yet signed with a code-signing certificate, so Windows SmartScreen shows "Windows protected your PC". Choose More info, then Run anyway. Signing is in progress; until then, check the SHA-256 below against the file you downloaded so you know it is the one we published.

What you need

  • Windows, 64-bit, on the server and on each PC: Windows 10 or 11, or Windows Server 2016 or later.
  • Disk space on the server for the backups. As a starting point, allow as much as the files you are protecting; it grows slowly after that because only changes are stored.
  • The same network. The PCs reach the server over your office LAN or Wi-Fi. Nothing needs opening to the internet, and nothing should be.
  • Administrator rights to run the installers.

Checking your download

To confirm a file is exactly the one published here, open PowerShell in the folder you saved it to and run:

Get-FileHash .\BackupMateServer-0.4.14.msi -Algorithm SHA256

The result should match the SHA-256 printed above, letter for letter. If it does not, do not install it; download it again, and tell us if it still differs.

Upgrading

Run the new installer over the old one. Nothing needs uninstalling and your settings and backups are kept. Upgrade the server first, then each PC. More on upgrading.

Installing on many PCs

Both installers run silently for deployment tools. See the silent install guide.
